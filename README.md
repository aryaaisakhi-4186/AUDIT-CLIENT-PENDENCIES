## ✨ Features
1. **Letterhead Format (Exact Specified Layout)**:
   - Line 1: `M/S. ARYA ASSOCIATES`
   - Line 2: **`CLIENT NAME`** (Large & Bold)
   - Line 3: `FINANCIAL YEAR 2025-26`
2. **Client Tabs**:
   - Add new client tabs with a single click.
   - Switch between clients seamlessly.
   - Rename and delete client tabs.
   - Each tab maintains its own independent pendency checklist.
3. **Audit Requirement Table**:
   - `Tick Box` — Toggle Received / Completed status with progress indicator.
   - `S. No.` — Auto-ordered serial numbers.
   - `PARTICULARS` — Document / data requirement description.
   - `PERIOD` — Audit period (e.g. FY 2025-26, Q1-Q4, Monthly).
   - `REMARK` — Auditor follow-up notes & client responses.
4. **CA Tools**:
   - **+ Standard Checklist**: Auto-populate 10 standard statutory audit requirements (Bank confirmations, FAR, 26AS/AIS, GST 2B recon, etc.).
   - **Print / PDF**: Official A4 letterhead format ready for client handover or email.
   - **Export Excel**: Download formatted CSV spreadsheet.
